# yt-redirector

Every time you reach for YouTube, read a page of your book instead. A slowly-growing
pause appears before YouTube loads — and hands you your own book to read while you wait.
Over days the delay quietly grows, so the habit fades instead of being fought.

Everything runs **locally in your browser** — no account, no tracking, nothing is uploaded.

## Features

**Free**
- A pause before YouTube that grows a little each day
- In-browser reader for **PDF / EPUB / TXT**
- One sentence at a time — read on for the next paragraph, or back over earlier ones
- Highlights, bookmarks, table of contents, jump-to-position
- Reading streak with a personal best
- Up to 3 books; System / Light / Dark / Sepia themes

**Pro** (one-time [license key](https://shaahid82.gumroad.com/l/nnrwcr))
- Unlimited books
- Extra themes — Nord & Solarized
- Sans-serif reading font
- Export highlights & bookmarks to Markdown

## Install (Brave / Chrome / Edge)

1. Download the latest `yt-redirector.zip` from **[Releases](../../releases)** and unzip it.
2. Open `brave://extensions` (or `chrome://extensions`).
3. Turn on **Developer mode** (top-right).
4. Click **Load unpacked** and select the unzipped folder.
5. Type `yt` in the address bar → instead of YouTube, you get a page of your book. 📖

To add books: right-click the extension icon → **Options** → drop in a PDF/EPUB/TXT.

## Privacy

100% local. Your books, highlights, and reading position live in your browser's storage
and never leave your device. The only network call is license verification (to Gumroad)
when you activate Pro.
