# Pageturn

Every time you reach for YouTube, read a page of your book instead. The site is swapped
for your own book, one sentence at a time, with a Continue button when you really want in.

Everything runs **locally in your browser** — no account, no tracking, nothing is uploaded.

## Features

- YouTube (and any site you add) opens to your book first, with a one-click Continue
- In-browser reader for **PDF / EPUB / TXT**, unlimited books on a cover shelf
- One sentence at a time — read on for the next paragraph, or back over earlier ones
- Highlights with notes, Markdown export, bookmarks, contents, search, jump-to-position
- Themes: System / Light / Dark / Sepia / Nord / Solarized / custom colours; serif or sans
- Backup & restore of everything

## Install (Brave / Chrome / Edge)

1. Download the latest `pageturn.zip` from **[Releases](../../releases)** and unzip it.
2. Open `brave://extensions` (or `chrome://extensions`).
3. Turn on **Developer mode** (top-right).
4. Click **Load unpacked** and select the unzipped folder.
5. Type `yt` in the address bar → instead of YouTube, you get a page of your book. 📖

To add books: right-click the extension icon → **Options** → drop in a PDF/EPUB/TXT.

## Privacy

100% local. Your books, highlights, and reading position live in your browser's storage
and never leave your device. The extension makes no network calls.
